# COC Digital Library

Vamos criar um layout de site baseado no https://biblion.org.br/. Crie uma aplicação web moderna e responsiva para uma biblioteca escolar chamada "Biblioteca COC Novomundo". O design deve ser elegante, intuitivo e inspirado em plataformas modernas de leitura, como Biblion, Goodreads e Kindle, mas com identidade própria.

Paleta de cores:

- Azul escuro como cor principal.

- Branco e tons de cinza claro para o fundo.

- Destaques em amarelo/dourado para avaliações e botões importantes.

A página inicial deve conter:

- Cabeçalho fixo com:

  - Logo da Biblioteca Digital.

  - Barra de pesquisa central.

  - Botão de Login.

  - Botão de Perfil (apenas visual).

  - Menu responsivo.

- Banner principal com uma imagem ilustrativa de biblioteca e uma mensagem incentivando a leitura.

- Seção "Categorias" exibida em cards:

  - Teatro

  - Africanidades

  - Contos

  - Literatura Brasileira

  - Fotos e Arte

  - Povos Originários

  - Poesia

  - Literatura Estrangeira

  - Juvenil 

  - Fantasia para crianças

  - Cordéis e Fábulas

  - Infantil

  - Aventura e Ação

  - Cartas
 - Política
  - Filosofia
  - Biografias
  - Autoajuda
  - Guerra
   - História
  -  Diários
   - Estudos
   - Turismo
   - Terror e Suspense
    - YouTube
    - Sensíveis
    - Quadrinhos
    - Sustentabilidade

- Seção "Livros em Destaque" em formato de carrossel.

- Seção "Novidades".

- Seção "Mais Bem Avaliados".

- Rodapé com:

  - Informações da biblioteca.

  - Horário de funcionamento.

  - Contato.

  - Redes sociais.

Utilize componentes modernos com cantos arredondados, sombras suaves, animações discretas e excelente experiência para desktop e dispositivos móveis.

Por enquanto, NÃO implemente nenhuma funcionalidade. Não conecte banco de dados, login ou APIs. Crie apenas a interface utilizando dados fictícios.
